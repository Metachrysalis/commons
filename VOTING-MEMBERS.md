# Metachrysalis Voting Membership Registry

This file is the authoritative public record of current formal Voting Membership in the official Metachrysalis Commons.

Voting Membership is distinct from Players Commons and Creators Commons Participating Membership.

| Voting Member            | Class                  | Term Begins      | Term Ends | Status |
| ------------------------ | ---------------------- | ---------------- | --------- | ------ |
| [Founding Voting Member] | Founding Voting Member | [effective date] | Permanent | Active |

Appointed Voting Members are added using the following format:

| Voting Member               | Class                   | Term Begins | Term Ends  | Status |
| --------------------------- | ----------------------- | ----------- | ---------- | ------ |
| [Name or public identifier] | Appointed Voting Member | YYYY-MM-DD  | YYYY-MM-DD | Active |

An Appointed Voting Membership expires automatically at the end of its listed term unless a new appointment is recorded.

Git history preserves previous states of this registry.
